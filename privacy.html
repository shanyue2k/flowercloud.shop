隐私保护政策

您的数字隐私至高无上。Flower Cloud 坚定捍卫每位用户的无痕安全通信权利。

🛡️ 核心承诺：严格的零使用日志政策

Flower Cloud 从架构设计的第一天起，就确立了“无痕运转、零日志存储”的核心技术准则。我们在服务器端系统配置中永久禁用了针对用户个人流量的日志记录机制：

  • 我们绝不记录：您访问的任何具体网站 URL、域名及网页内容；
  • 我们绝不记录：您的真实源 IP 地址与连接后的目标服务器 IP；
  • 我们绝不记录：任何通过专线代理中继的 DNS 查询记录；
  • 我们绝不记录：您在网络上传输的通信文本、媒体文件或下载历史；
  • 我们绝不记录：任何能够反向关联到您个人身份与真实设备的连接时间戳。

由于我们根本不收集或存储上述任何数据，因此即使在面对第三方的调取要求时，我们也无法提供任何不存在的数据。您的网络行为完全属于您自己。

🔒 我们仅收集哪些必要的基础运维信息？

为了保障账户系统的正常计费、防范针对系统本身的滥用以及维持网络负载均衡，我们仅保留最精简的技术参数：

  • 注册账户凭证：您注册时填写的电子邮箱地址（支持 ProtonMail、Gmail 等各类匿名邮箱）以及经过单向强哈希加密的登录密码。
  • 套餐计量数据：当前账期内已消耗的总体流量配额数值（仅为流量总字节数计数，不含流量来源与具体内容）以及当前并发在线的设备连接数量。
  • 支付交易单号：由第三方支付网关（如支付宝、加密货币区块链浏览器）生成的匿名交易流水号，用于确认订单开通，本站绝不存储您的信用卡卡号、CVC 码或银行卡信息。

🔑 数据加密与传输安全

Flower Cloud 的所有网络中继节点通信均强制使用业界主流的现代加密算法（如 AES-256-GCM、ChaCha20-Poly1305），在客户端与中继服务器之间建立安全隧道，有效防御中间人攻击（MITM）、公共 Wi-Fi 嗅探及 ISP 旁路数据分析。

🚫 第三方商业数据披露

我们郑重承诺：绝不会向任何第三方广告商、数据分析机构或商业实体出售、出租、交换或分享您的任何个人数据。 Flower Cloud 的唯一商业模式是向用户提供优质的网络加速技术服务，而非通过售卖用户数据牟利。

📧 隐私联络

如果您对本隐私政策有任何疑问或需要请求注销删除您的账户信息，请通过后台工单系统或联系官方在线支持。
